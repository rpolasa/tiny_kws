Builds a new chip model from your recordings. The trained 16-band front end and 48-unit GRU stay as they are; only the classifier layer is retrained on GRU states captured live from your microphone (plus stored Speech Commands states), then quantised to the chip's int8/24-bit format and written as a model blob. Classes 0 and 1 are always silence and unknown (NFILL = 2). The chip allows up to 16 classes.

Register settings for running the tt_um_rakesh_tiny_kws silicon at your clock. Load the model with CTRL.RUN = 0 (the QSPI bus is released), write the registers below in order, CTRL last. CTRL always carries HOP512 (the model uses 32 ms frames; the reset value is the 16 ms hop) and CLEAR: write CLEAR whenever RUN is set again, because RUN cleared in mid-frame leaves the network engine waiting until CLEAR. BURST has to follow the clock so PSRAM chip-select stays under 8 µs.

Say the words in order, each within 5 s of the last. A wrong word starts over; three wrong words in a row lock the
              door for 10 s. This is a convenience lock, not security: the chip recognises words, not voices.

            
On the silicon: the sequence check is a few flip-flops on the DET_CLASS nibble, clocked by the DETECT edge —
              a CPLD, a small FPGA or a few lines of MicroPython. The microphone, filter bank and network stay inside the chip; only the class of
              each detected word leaves it.

On the silicon: FRAME (uo[3]) toggles once per processed frame, DETECT (uo[2]) is high for the frame a keyword is
          detected and DET_CLASS (uo[7:4]) holds the class of the last detection. Probe them with a logic analyser to compare with this view;
          the hidden state is internal and only visible here.

      

    

  

  
This page runs the bit-exact software model of the tt_um_rakesh_tiny_kws chip: the same integer filterbank, GRU, detector and model blob
    as the silicon (rev B, 4x2 tiles; rev A, 6x2, computes identical results). Live audio needs microphone permission; open this file in Chrome or Edge. If the browser refuses the microphone on a file:// page,
    serve the folder with python -m http.server and open http://localhost:8000/app/kws_live.html.
